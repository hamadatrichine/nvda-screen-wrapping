# Navigationsschleife für den Lesemodus

* Autor: Hamada Trichine
* Laden Sie die [stabile Version][1] hier herunter

Diese Erweiterung bringt die Navigationsschleife-Funktionalität zum Lesemodus.

Eine Navigationsschleife ist eine Funktion, bei der die Navigation mit den Schnellnavigationstasten zum Anfang der Seite zurückkehrt, wenn keine weiteren Elemente des verwendeten Typs vorhanden sind. Wenn wir die Schnellnavigationstasten in die entgegengesetzte Richtung verwenden, also vom Ende zum Anfang, führt uns die Schleife zum Ende des Dokuments zurück.

## Nutzung

Die Verwendung dieser Erweiterung ist einfach. Befolgen Sie einfach die folgenden Schritte:

 1. Installieren Sie das Add-on;
 2. Durchsuchen Sie die Webseiten mit den Schnellnavigationstasten oder versuchen Sie, eine Suche mit NVDA+STRG+F (Standardbefehl) durchzuführen.
Hinweis: Bei einer Suche hängt die Schleifennavigation vom Kontrollkästchen im Dialogfeld „Suchen“ ab. Wenn das Kontrollkästchen „In Schleife suchen“ aktiviert ist, erfolgt die Wiederholung einer Suche mit NVDA+f3/NVDA+UMSCHALT+f3 kreisförmig. Wenn es deaktiviert ist, wird das Standardverhalten übernommen.
 3. Sie können die Navigationsschleife mit **nvda+h** aktivieren oder deaktivieren.
  Hinweis: Sie können den Standardbefehl im Dialogfeld „NVDA-Befehle festlegen“ in der Kategorie „Navigationsmodus“ ändern.
